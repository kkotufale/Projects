## Opening and running files

- **Excel:** Download the `.xlsm` files and open them in Microsoft Excel. These are macro-enabled workbooks.
- **Tableau:** Download the `.twbx` files and open them in a compatible Tableau application.
- **Python:** The scripts use Python 3 and depend on the course utility module `cis2010utils4`, which is not included in this repository.
- **Additional dependencies:** Logic 3 and the SQL script import `pandas`. Logic 3 also reads `GAcodes.csv`; the SQL script expects `Movies2023x4.db`. Neither data file is included.

The Python scripts require their original course utilities and data to run as written. Installing pandas alone does not supply these missing files.
